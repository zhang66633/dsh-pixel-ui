# Complete UI Essential Pack · Stone theme

Selected sprites from **Complete UI Essential Pack v2.4** by
**Crusenho Agus Hennihuno** (<https://crusenho.itch.io>), used under the
**Creative Commons Attribution 4.0 International (CC BY 4.0)** license:
<https://creativecommons.org/licenses/by/4.0/>.

The sprites are used unmodified as 9-slice textures in the `pixel-marble`
theme. They are inlined into the client bundle as data URIs at build time
(`scripts/asset-inline.mjs`).

- Original pack: Complete UI Essential Pack v2.4
- Theme: `04_Stone_Theme`
- License text: `LICENSE.txt` in this directory.

| Local file | Source sprite | Role |
| --- | --- | --- |
| `panel.png` | `UI_Stone_Frame_Standard_01a.png` | dialog frame |
| `popover.png` | `UI_Stone_Frame_Lite_01a.png` | menu / popover frame |
| `button.png` | `UI_Stone_Button_Large_Release_01a1.png` | primary button (rest) |
| `button-hover.png` | `UI_Stone_Button_Large_Press_01a1.png` | primary button (hover) |
| `button-press.png` | `UI_Stone_Button_Large_Lock_01a1.png` | primary button (pressed) |
| `icon-button.png` | `UI_Stone_Button_Small_Release_01a1.png` | icon-only primary button |
| `input.png` | `UI_Stone_Textfield_01a.png` | text field |
| `select.png` | `UI_Stone_Dropdown_01a.png` | selected row / menu item |

Modifications: none to the images; only CSS border-image slicing/repeating is
applied at runtime.
