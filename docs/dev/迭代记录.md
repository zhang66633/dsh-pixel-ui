## v1.5.0（2026-10-01）· 桌面端「一半一半」+ 去伪像素 + 完全平面

### 动机
两条用户原话：
1. 「在桌面端会出现这种一半一半的情况，修一下；同时整体优化，改善那种伪像素
   （比如任务那一长条，内部一大堆线），使其趋近于真实像素质感」
2. 「不要加立体效果了，我感觉这样就不错，能不能实现」

### 定位过程（都是实测，不是推测）
| 步骤 | 手段 | 结论 |
| --- | --- | --- |
| 截图取证 | `BitBlt` 抓 DSH 窗口客户区（GPU 合成窗口必须从屏幕 DC 抓，`PrintWindow` 只出空图） | 复现「左边一窄条正文 + 右侧空背景」 |
| 尺寸对齐 | 窗口 1619×1036 物理 / DPR 1.25 | CSS 视口 1281×821 |
| 源码定位 | `app.asar` 全量 `grep -a` + `@deepseek-ai/dsh-client-ui-conversation` 的 CSS | 宿主 clamp 恒取 680px（踩坑 #7） |
| 皮肤为何不激活 | index 注入式探针读 `data-pixel-ui` | 桌面端 origin 是 `dsh-app://app`，相对 fetch 到不了宿主路由（踩坑 #8） |
| 视觉为何「凹陷」 | 对照 v1.4 的 `[class*=...]` 规则与宿主真实类名 | 子串选择器误伤宿主容器（踩坑 #6） |

### 改动清单
1. **`lib/index.js`（node 半边）**：新增 `webserver/index-inject` 订阅，把
   `{ theme }` 以全局 `__DSH_PIXEL_UI__` 注入页面启动数据（桌面端唯一能拿到的记忆通道）。
2. **`src/client/index.js`**：
   - 新增 `readBootTheme()`，`readHostTheme()` 变成「注入优先 → HTTP 路由兜底」；
   - 恢复时序重排：`restoring` 标志在**应用完目标皮肤后立即**放掉，避免宿主的初始
     preference 在异步窗口里被当成用户选择；
   - 首次安装仍默认 `pixel-wood`，且应用失败会隔 120ms 重试一次。
3. **`src/client/pixel.css`：整表重写（903 → ~610 行）**：
   - **平面化**：全表 0 个 `box-shadow` / `text-shadow`（用户决定不要立体）；层次改由
     整像素描边 + 平涂明度差 + 2px 棋盘抖动 + 手绘 SVG 像素图形表达；
   - **选择器收口**：只保留 HTML 语义 / ARIA-data 属性 / 自有 `.px-*`；删掉全部
     无前缀 `[class*=...]`（保留一条有注释的列宽兜底）；
   - **列宽修正**：根作用域补 `--dsh-conversation-column-width` 与
     `--dsh-chat-user-width`（`!important`，压过宿主内联），新增
     `--px-chat-width: clamp(680px, 64vw - 140px, 1200px)`；
   - 2px 棋盘抖动替代 1px 细线纹理；页签改「文字 + 3px 金色下边线」（不再套黑框）；
   - `letter-spacing: 0`（0.01em 会把字形推到半像素）。
4. **测试**：host 20 条（+3：注入表内容与随 dispose 释放）、client 26 条
   （+3：桌面注入通道、迟到内置偏好、平面/选择器门禁）。新增门禁断言：
   **禁止 `box-shadow`/`text-shadow`/`blur()`/`--px-bevel`/无前缀 `[class*=...]`**。
5. **`.gitignore`**：忽略 `TEMP/`（一次性探针与截图）与 `lib/*.orig`。
6. **docs/dev**：新增踩坑 #6/#7/#8，重写本篇与开发计划。

### 验证
- `npm test` 全绿：host 20 / client 26 / contrast ALL PASS。
- 桌面端实测（1920×1200 @125%，pixel-wood 与 pixel-paper 各一轮）：
  探针量到 `col=843|scroll=1241|vw=1536`（修复前恒 `col=680`）；
  截图确认平面皮肤、页签金下沿、无毛边。
- 未在本机验证：Web 部署（`http://127.0.0.1:<port>`）那条 HTTP 兜底路径——由
  client 测试的 fake fetch 覆盖；真实浏览器待用时确认。

### 遗留 / 下一步候选
- 桌面端 renderer 的 `dsh-app://app/` 下 `/api/*` 仍 404（宿主自身问题，非本插件；
  用户在另一个会话里查）；本插件已不再依赖该 origin 的任何 HTTP 路径。
- CRT 扫描线彻底移除，只留径向暗角；若日后想开，`--px-scan` 仍可复用
  （注意非整数 DPR 的糊线问题，见踩坑 #6）。

## v1.4.0（2026-10-01）· DSH 0.2.x 适配 + UI/UX 重构

### 动机
用户要求「最新版本适配，尤其是桌面端 + UI/UX 界面重构优化」。运行时已到 0.2.0-rc.2；v1.3.0 peer 范围不含 0.2.x（本地改过 peer 才加载），且 09-28 遗留「加载了但证不了渲染结果」的悬案。

### 契约核对结论（源码级，app.asar 提取）
| 契约 | 0.2.0-rc.2 行为 | 与 v1.3.0 假设是否一致 |
| --- | --- | --- |
| `ctx.theme.register({id,colorScheme,tokens})` | 一致（重复 id 抛错） | ✅ |
| `ctx.theme.setTheme(id \| 'system')` | 一致（未注册 id 抛错） | ✅ |
| `ctx.theme.getTheme()` / `theme/change` | snapshot 多出 `fontSize` 字段，`active/…/revision` 不变 | ✅ 兼容 |
| `ctx.slots.inject/inject→register({name,id,order,store,inject,locale}, Comp)` | 一致；`t` 经 `locale` 选项下发 | ✅ |
| `defineStore({init,actions})`（`@deepseek-ai/dsh-client-store`） | 0.1.7-rc.2 与 0.2.0-rc.2 均导出，接口一致（新增 `persist`，未用） | ✅ |
| `ctx.webServer.register({kind:'exact'\|'prefix', path, handler})` | 一致（重复路径抛错） | ✅ |
| wire 格式 `window.__ModuleLoader__.load({id, factory})` | 一致 | ✅ |
| token 集 | 新增 `--dsw-alias-state-idle-primary` | ⚠️ 已补进四个主题 |
| 兼容判定 | app-boot 只读 peerDependencies（`includePrerelease:true`），豁免走 `dsh plugin allow-version` + profile `compatibility.json` | ℹ️ 指导 peer 写法 |

### 改动清单
1. **package.json**：1.3.0 → 1.4.0；peer 范围改为 cost-meter 式多段范围（覆盖 0.1.0-rc.6~0.2.x，semver 实测 5 运行时全过）；新增 `dsh.compatibility.dshReleases` 声明表；新增 `@deepseek-ai/dsh-home-paths` peer（node 半边用）；`scripts` 增加 test 三件套。
2. **lib/index.js（node 半边）**：新增 `/dsh-pixel-ui/preference`（GET 读 / PUT 写 / 其他 405），落盘 `$DSH_HOME/storages/dsh-pixel-ui/preference.json`（tmp+rename 原子写，id 白名单 `light|dark|system|pixel-*`）；字体路由逻辑不动。
3. **src/client/index.js（browser 半边）**：
   - 持久化两层化：localStorage 镜像 + host 文件；恢复顺序「本地同步生效 → 本地缺失等 host → 都不缺以 host 为准」；
   - **修复 first-run 不激活**（见踩坑 #1）：监听器不再把注册期 publish 的内置偏好写进记忆；读取边界做 RESTORABLE 归一化；
   - 设置行改 `role=group` + `aria-pressed` + swatch `aria-hidden` + desc helper text；locale 字典 `settings.pixel-ui`（zh/en）；
   - `inject` 增加 `locale`。
4. **src/client/pixel.css**：palette 对比度修正（14 处 → 0）；新增解耦变量 `--px-tooltip-bg`、`--px-accent-bg/-ink`、`--px-ink-on-mid`、`--px-code-bg/-ink`；设置行全段 token 化 + `--dsw-alias-*` 回落 + 焦点环 + 32px 触摸目标。
5. **scripts/**：新增 `audit-contrast.mjs`（WCAG 审计门禁）、`test-host.mjs`（17 项）、`test-client.mjs`（21 项，加载真实 lib/client.js 跑 wire 格式 + 行为矩阵）、`resolve-dsh-peers.mjs`（测试专用 peer 解析 hook）。
6. **docs/dev/**：新建（计划/迭代/踩坑）。

### 验证
- 三套测试全绿（17/21/ALL PASS），`npm run build` 成功。
- 宿主 fonts 路由在运行中的 0.2.0-rc.2 上实测：woff2/ttf 200 且 content-type 正确；白名单外 404；`..%2f` 穿越 404。
- preference 路由为**新增**路由：运行中的宿主进程加载的是旧 lib/index.js，需下次桌面端重启后生效；客户端对 404 已做降级（本地镜像照常工作），测试用 fake req/res 全量覆盖。

### 遗留 / 下一步候选
- 设置行可继续用 `@deepseek-ai/dsh-client-ui-primitives` 的图标与官方 AppearanceRow 视觉对齐（评估后暂缓：像素风以 swatch 为标识，语义更直接）。
- 羊皮纸主题截图需重拍（palette 已变，旧截图的选中态/提示框颜色过时）。
