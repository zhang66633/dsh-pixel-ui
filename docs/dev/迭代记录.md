## v1.8.1（2026-10-31）· 素材边框占位修复 + 南瓜灯对比度 + README 主题图

### 动机
补 README 主题图时，把三套素材主题的组件板放大看，暴露两个问题：

1. **多值 border shorthand 无效**：素材层写的是
   `border: var(--pxa-panel-width) solid transparent`，而 papernote 的
   `--pxa-panel-width` 是 `12px 8px 12px 18px`。CSS `border` 简写只接受**一个**
   `<line-width>`；四值版是 `border-width`。浏览器在计算期丢弃整条声明，
   `border-width` 回落 0，但 `border-image-width` 仍按 `/ 12px 8px …` 绘制——
   于是边框图盖在内容上：便签本对话框标题压在撕边、按钮文字贴边。
   pumpkin 的 button/icon/input 与 hologram 的 6px 10px 按钮同样受影响。
2. **南瓜灯对比度**：按钮/图标键/输入框素材的填充是 `#BF5F16`，奶油字只有
   4.03:1，占位符更低；审计只查了 token 的 `#8A3E0C` / `#3A2210`，没覆盖到
   素材填充本身。

### 改动
1. 六条素材规则（dialog / menu / button / icon / input / select）改成
   `border: 0 solid transparent !important;` + `border-width: var(--pxa-*-width) !important;`
   ——longhand 支持 1–4 值，边框重新占位。hologram/pumpkin/papernote 都受益。
2. 南瓜灯素材改色：button/button-hover/button-press/icon-button 的填充
   `#BF5F16 → #8A3E0C`，input `#BF5F16 → #3A2210`（与 token 对齐）；
   奶油字 7.05:1、占位符 9.45:1。ATTRIBUTION 已按 CC BY 记录 Modifications。
3. README 增加三套素材主题的 1200×760 静态组件预览（真实 CSS + 素材，
   headless 渲染，非实机会话），并更新前四套实机截图的说明；版本 1.8.1。
4. `scripts/test-client.mjs` 新增门禁：panel/button/input 的 border-width
   longhand 必须存在，且素材层不得再出现 `border: var(--pxa-…`。

### 验证

## v1.6.0（2026-10-25）· 细节与阶梯动效 pass

### 动机
用户要求「对目前的像素风格进行优化，细节、动感等，逐一细节优化」。v1.5.0
已经平面化，但只有按钮有 60ms 过渡；页签、状态点、思考中、toast、运行中终端
仍是宿主的平滑动效，和像素语言不一致。

### 改动（按层）
1. **动效 token**：`--px-t-fast/mid/slow`（80/140/220ms）与
   `--px-step-2/4/8`；所有新动效统一走 `steps()`，不写 `transition: all`。
2. **按钮**：主按钮加主题 token（`--dsw-alias-button-primary-fill/-hover`、
   `--dsw-alias-label-primary-foreground`），发送/确认不再带宿主蓝；hover 叠 2px
   棋盘 dither，按下 1px 整像素位移；普通按钮 hover 不再误刷主/危险按钮。
3. **页签**：金色下划线改用 `::after` + `scaleX`，140ms `steps(4)` 生长；透明
   3px border 正好被盖住，和分隔线齐平。
4. **输入/选择件**：hover 提亮边框、`caret-shape: block`、方块光标；勾/点改用
   `--px-check` / `--px-radio` 变量，纸面主题换成纸白勾（深金底上深勾只有 ~2:1）。
5. **代码/表格**：`pre` 左侧 4px 金条；`[data-code-block-banner]` 终端顶栏；
   表格斑马纹 + 行 hover；hr 改 2px 虚线；`kbd` 键帽、`mark` 金底。
6. **导航/菜单**：`[aria-current=page]` 3px 金左条；菜单 2px 边；treeitem hover/
   selected；`[data-stuck]` 吸顶标题 2px 底线 + dither。
7. **反馈层**：toast 2px 框 + 4px 金左条 + 220ms `steps(3)` 进入；
   dialog 四角像素角标；tooltip 左上 6px 角标；标签 2px 左侧色条（落在 8px 内边距里，不改宽）。
8. **宿主状态**：思考 shimmer 的 1.5s 平滑扫光改 `steps(4)`，左侧补 2px 闪烁光标
   （用 background 不用 border，避免复制文本右移重影）；运行中终端左条
   `steps(2)` 呼吸；ongoing 点闪烁；spinner 改 `steps(8)`。
9. **滚动条**：4×2 像素握把 + hover/active 换色；纸面主题换深棕光标。
10. **无障碍**：reduced-motion 连 `*::before/*::after` 一起关；探针确认 tab
    transition 也归零。
11. **会话行 hover + 光标（用户实测反馈）**：宿主把 session/project 行写成
    `[role=treeitem]`，不是 button/a；选中行又用 `aria-selected` 的背景规则，
    会盖掉 `:hover`，所以悬停没反应。补 `[aria-selected=true]:hover` 提亮、
    未选行 2px `--px-gold-deep` 左条 + 文字提亮；把 `[role=treeitem]` /
    `[role=option]` / `[role=button]` / `[aria-selected]` / `[aria-current]`
    加进像素手规则，并让行内非文本子元素 `cursor:inherit`，不再退回宿主自带小手。
12. **面板导航 hover（用户实测反馈）**：插件/插件市场/自动化任务等是
    `button.panelRow`；generic hover 用 `--px-wood-dark`，而纸面主题的
    `--px-wood-dark` 与 `--px-sidebar-fill` 都是 `#E8DCC8`——等于 hover 前后同色，
    看起来完全没交互。改成 `--px-wood-mid`；`[aria-current=page]` 给 wood-mid 底 +
    金左条，hover 再叠 2px dither，当前项也有可见反馈。
